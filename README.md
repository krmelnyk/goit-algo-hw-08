# goit-algo-hw-08

Домашня робота до тем 7 та 8.

## Завдання 1

Файл `task_1_min_value.py` містить реалізацію двійкового дерева пошуку та функцію `find_min_value`, яка знаходить найменше значення в дереві.

Запуск:

```bash
python3 task_1_min_value.py
```

## Завдання 2

Файл `task_2_sum_values.py` містить реалізацію двійкового дерева пошуку та функцію `sum_tree_values`, яка знаходить суму всіх значень у дереві.

Запуск:

```bash
python3 task_2_sum_values.py
```

## Завдання 3

Файл `task_3_cables_heap.py` містить функцію `min_connection_cost`, яка за допомогою мін-купи знаходить мінімальну загальну вартість об'єднання кабелів.

Запуск:

```bash
python3 task_3_cables_heap.py
```
